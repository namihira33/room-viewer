# 参考資料と判断記録

## 使用資料

- ユーザーがこのチャットに添付した1LDK間取り画像。
- ユーザーが添付したIMG_0494.MOV（コンテナ計測100.7017秒、映像1920×1080、30fps）。
- ユーザー添付three.js_mini.zip（build/three.core.jsのREVISION='186'）。

元資料、動画のフレーム、映り込んだ人物・位置情報は公開用フォルダに同梱していません。

## 動画の視覚確認

全域：約4秒間隔25フレーム（サンプリング区間中心は約2,6,10,...,98秒）。
補助フレーム：12,15,16,17,19,23,28,31,33,35,36,39,41,44,52,56,60,63,65,68,72,75,80,83,85,87,89,91,95,99秒。

| およその時点 | 確認した内容 | モデルへの反映 |
|---|---|---|
| 2〜12秒 | 玄関扉、玄関タイル、木製シューズ収納 | グレー扉、グレーのタイル、背の高い茶色収納 |
| 14〜31秒 | 木目床、白い壁、茶色のドア・引戸、梁型 | 木目仕上げ、室内建具、下がり梁の概略 |
| 33〜42秒 | 白いキッチン、ステンレス天板、黒いIH、フード、キッチン窓 | 左記の設備。冷蔵庫を勝手に置かない |
| 46〜62秒 | 洗面・トイレへの建具、白い便器、小窓 | 水まわり配置は図面優先。便器・扉・小窓を近似 |

## 不確実性

- 図面上にメートル寸法がない。全寸法を仮定した。帖数から規格面積を断定しない。
- 壁の中心線、仕上げ厚、有効面積の違いを精密に復元していない。
- 図面と動画だけでは開き勝手、収納内部、細かいコンセント位置等を一意に決められない。
- 窓・エアコン・キッチン・浴槽等は実在製品の正確なCADではない。
- ガラス・鏡はマテリアル近似。反射映像や透過した近隣建物を再現していない。
- パノラマ・SfM・NeRF・Gaussian Splatting等による自動3D復元ではない。
- 天井・屋根を意図的に省略した模型。外壁の外装は目的外のため簡略化。
- 住所、号室、ブランドロゴ、人物、掲示内容、私物は再現していない。
